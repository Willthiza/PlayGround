## UMBRA — Ceniza y juramento

Una aventura 2D de plataformas con combate exigente, exploración lateral y una atmósfera de fantasía oscura. Recorre cuatro zonas, derrota enemigos, activa altares para fijar tu punto de retorno y enfrenta al Caballero Hueco.

### Jugar

Abre `index.html` en un navegador moderno o sirve esta carpeta con cualquier servidor estático. No requiere dependencias ni conexión a internet.

- **A / D** o **← / →**: moverse · **Espacio**: saltar
- **J**: atacar · **K** o **Mayús**: esquivar
- **H**: gastar aguante para curarse (en los altares, compra un corazón por 100 almas)
- **E**: activar altares o recuperar las almas perdidas al caer

Derrota enemigos para reunir almas. Al caer, las dejarás en el lugar de tu muerte: recupéralas antes de morir otra vez. En móviles, usa los controles táctiles en pantalla.
